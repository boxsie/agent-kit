# personal kit

How I like to work with a coding agent, plus the lessons that shaped it. No project data in here.

## install

```sh
./install.sh
```

- adds a marked block to `~/.claude/CLAUDE.md` (appends if it's new, replaces its own block on re-run, leaves everything else alone)
- copies `lessons/*.md` to `~/.claude/lessons/`. The CLAUDE.md block lists them one line each, and the agent reads the full story when one applies.

## the one rule

**This kit is one-way.** It goes into the work machine, and nothing comes back out. Work code, names, tickets and memories stay at work. If a genuinely new *generic* lesson turns up at work, rewrite it from scratch at home. Never copy it across.

Check the company AI policy is happy with a personal `~/.claude/CLAUDE.md` before installing.
